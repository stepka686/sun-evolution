# Эволюция Солнца — правила проекта

Хобби-проект: интерактивная симуляция эволюции звёзд, планет, климата и неба. Один самодостаточный HTML, собранный из ES-модулей.
Автор — студент (физика + электротехника), работает в основном **с телефона на Android**. Любит графики и красивую графику; цель каждой версии — чтобы было «абалдеть», но физически честно.

## Общение
- Только по-русски. Тон — наглый кореш, знакомы 10 лет: сарказм, мат к месту, дружеские подъёбы («балбес»), без канцелярита и нравоучений.
- На серьёзный вопрос — точный ответ по существу, шутки не в ущерб точности.
- Ответы короткие (читаются с телефона), картинки и графики приветствуются.

## Команды
```bash
npm install          # esbuild
npm test             # node:test, tests/*.test.js — должно быть 0 fail
npm run build        # dist/sun_evolution_v<версия из package.json>.html
npm run dev          # http://localhost:8000
```
Браузерные проверки (нужны Playwright и Chrome; пути — в `tools/check/_env.cjs`, переменные PLAYWRIGHT_DIR, CHROME):
```bash
node tools/check/regress.cjs                 # прогон звёзд × возрастов × планет × видов, ждём "errors: none"
node tools/check/mobile.cjs                  # раскладка на 390×844
node tools/check/ui.cjs                      # перекрытия панелей и меню
node tools/check/fps.cjs [виды] [версии]     # FPS по видам, по умолчанию 4.3.0 против текущей
node tools/check/profile.cjs space,orbit     # CDP-профиль по видам
node tools/check/skytour.cjs                 # 12 кадров неба
node tools/check/compare-shots.cjs 5.2.1,5.2.2
node tools/check/andromeda.cjs mars 4.57,8.6   # Андромеда на небе: сама ищет ночь, когда M31 выше всего
node tools/check/clouds.cjs 15,19.6          # объёмные облака и лучи (CU=облачность, NORAYS=1, AWAY=1)
```
Снимки и отчёты падают в `tools/check/out/` (в git не идёт). Headless работает на swiftshader — **FPS там не равен телефонному**, это только сравнение версий между собой; реальные цифры спрашивать у автора.

## Устройство
- `src/physics/` — модели (треки MIST, орбиты, климат, оптика неба `skyModel.js`, спектры прохождения). Чистые функции, покрыты тестами.
- `src/render/` — 2D-отрисовка видов (space, orbit, surface, moonView, galaxyView, star …).
- `src/gl/` — WebGL-слой (5.0+): один offscreen GL-холст (`glcore.js`), шейдеры неба/облаков (`skyGL.js`), шаров планет (`sphereGL.js`), диска звезды (`starGL.js`), Галактики (`galaxyGL.js`). Результат копируется в 2D через `drawImage`.
  - Копирование из GL — самая дорогая операция на телефоне. Медленные слои кэшировать через `makeLayerCache/layerFresh/layerStore`.
  - Всегда есть 2D-запасной путь (нет WebGL / потерян контекст / `S.renderer = '2d'`).
  - Формулы в шейдерах обязаны совпадать с JS-эталоном в `physics/` — это проверяют тесты.
- `src/ui/` — панели, цикл (`loop.js`), адаптивный DPR (`perf.js`), телескоп, HUD.
- `src/audio/` — звук звезды (p-моды).
- `tools/mist`, `tools/sky`, … — Python-генераторы данных.
- `releases/` — собранные HTML всех версий (для сравнения и скачивания). `changelog/` — логи версий. `docs/` — техническая документация, история версий, картинки README. Сайт на GitHub Pages собирается CI из `main`.

## Порядок выпуска версии
1. Код + тесты на новую физику (сверка с литературой/эталоном, а не «на глаз»).
2. `npm test` → 0 fail; `regress.cjs` → `errors: none`; `mobile.cjs`/`ui.cjs` — без наложений; глянуть снимки.
3. Поднять версию в `package.json`; заголовок в `src/index.html` и метка в `src/ui/panels.js` — для минорных версий; раздел о версии — в `docs/DEVELOPMENT.md`.
   README — витрина: при выпуске обновить бейджи (версия, число тестов, размер) и ссылку «Скачать HTML»; если версия меняет внешний вид — переснять картинки (`npm run dev` + `node tools/check/readme-shots.cjs`, гифка — `node tools/check/readme-gif.cjs` по сборке).
4. `npm run build`, скопировать `dist/*.html` в `releases/`.
5. История: строка в таблице `docs/HISTORY.md` (лог + сборка) и график `python tools/stats/lines_growth.py`.
6. Лог `changelog/vX.Y[.Z].txt` — **только когда автор просит** («Сделай лог»). Формат:
   ```
   <Название версии одной строкой>
   Добавлено:
   - ...

   Изменено:
   - ...

   Исправлено:
   - ...
   ```
   Пишется для человека, без имён функций и файлов.

## Принципы
- Физика честная: формулы с источниками, калибровка по реальным данным (фото неба, Kaltenegger & Traub, MIST и т. п.). Если что-то преувеличено ради красоты — сказать об этом прямо.
- Телефон — главная платформа: ориентир ≥ 50 к/с на всех видах (как в 4.1–4.3). Новое тяжёлое — с кэшем и деградацией качества.
- Известные недоделки сообщать честно, а не прятать.

- 5.4 (сделано): Андромеда — орбита M31 в трёх сценариях (HST 2012, Gaia 2026, Gaia 2025), на небе, приливные хвосты, слияние; график в виде «Галактика». Недоделки: без БМО и M33, Солнце не уходит на новую орбиту, диск Галактики не искажается.

- 5.5.1 (сделано): рывки — GL-холст только растёт (пересоздание буфера съедало >50% кадра), поле облаков в текстуре, счётчик `?fps` в адресе (к/с, худший кадр, ступень качества) — реальные цифры просить у автора через него.
- 5.6: вид «Космос» целиком на GPU, настоящий HDR.
- Мелочи: великоват синий ореол в полдень на Марсе; зелёный луч преувеличен; замёрзший грунт Венеры не белеет от сухого льда.
